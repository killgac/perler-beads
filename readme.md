# 拼豆图纸工具 🧩

**👉 在线使用（电脑和手机通用）：https://killgac.github.io/perler-beads/**

把喜欢的图片变成拼豆图纸：上传照片，自动配好实体豆色，照着图纸拼就行。也可以直接在空白画布上画自己的设计。

## 能做什么

- **照片变图纸**：上传一张图片，自动转成拼豆图纸，每个格子标好色号
- **三个豆子品牌**：Perler / Artkal / Hama 一键切换，图纸跟着变
- **随手改**：点一下或拖着画就能改色，画错了撤销就行跟画图一样
- **材料清单**：每种颜色各要多少颗自动算好，照单买豆子不浪费
- **空白创作**：不想传图就直接新建画布自己画
- **导出图纸**：存成 PNG 图片或 PDF（含材料清单页），打印出来照着拼

## 怎么玩（电脑）

1. 打开上方在线地址
2. 上传一张图片（或者点空白创作自己画）
3. 右侧选尺寸和豆子品牌
4. 在中间图纸上微调颜色：左侧色盘或右侧用量表点选颜色再点图纸
5. 导出 PNG 或 PDF，照着拼

布局是三栏：左侧取色、中间图纸、右侧设置和用量。

## 怎么玩（手机）

手机打开同一个地址就能用，页面会自动变成单列，顺序是图纸优先：

1. 先看到的是**图纸**（上传前是空状态提示）
2. 往下滑是**取色 / 用量**
3. 再往下滑是**上传 / 品牌 / 导出**

步骤和电脑一样：先在最下面的上传卡里选图，再滑回图纸处点画改色，最后滑到底导出。

## 手机操作说明

- **点画 / 拖涂**：手指点一下改一格，按住拖着走连着改，橡皮擦模式下点格子擦为空白
- **缩放**：图纸下方有缩放条，新图会自动缩到整图正好占满宽，看不清就拉大或点自适应整图
- **目标宽度**：输入框里输数字后要点别处或按回车才生效清空不保存，范围是 8～256 颗建议 24～96
- **品牌切换**：切品牌会重算整图，手改会被覆盖但可以撤销回来
- **顶栏**：手机上只留标题和模式切换，尺寸统计藏起来了图纸下方的尺寸行还能看到

## 常见情况

- **刚更新完还是旧样子**：微信里打开过旧页面会被缓存，彻底关掉重进或清缓存再开
- **大图在手机上白屏**：显示画布长边已限 2048 超了自动缩小格宽再画，导出走单独高清图不受影响
- **作品丢了**：作品只存在当前浏览器里，换浏览器 / 无痕模式 / 清缓存会丢，拼完记得导出 PNG / PDF 留底

作品会自动保存在浏览器里，刷新页面不会丢。
